# 实验室官网项目

基于 Vue 3 + TypeScript + Vite 构建的实验室官方网站。

## 技术栈

- Vue 3 - 渐进式 JavaScript 框架
- TypeScript - JavaScript 的超集，添加了类型系统
- Vite - 下一代前端构建工具
- Element Plus - 基于 Vue 3 的组件库
- Vue I18n - 国际化解决方案

## 功能特性

- 响应式设计，适配多种设备
- 新闻轮播展示
- 多语言支持（中文/英文）
- 新闻动态列表
- 通知公告系统
- 研究亮点展示
- 侧边栏快速导航

## 项目结构

- `src/` - 源代码目录
  - `components/` - 组件目录
  - `views/` - 页面目录
  - `App.vue` - 主应用组件
  - `main.ts` - 入口文件
  - `router.ts` - 路由配置
  - `store.ts` - Vuex 状态管理
  - `i18n.ts` - 国际化配置
  - `utils/` - 工具函数目录
  - `assets/` - 静态资源目录
  - `styles/` - 全局样式目录

## 安装依赖

```bash
pnpm install
```

## 运行项目

```bash
pnpm run dev
```
